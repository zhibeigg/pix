# Pix 用户向介绍视频 · 文案与录制脚本

> 项目：Pix · AI 像素素材生成服务
> 面向：独立游戏开发者、像素美术爱好者、Game Jam 选手、独立工作室美术
> 视频时长：2 分 30 秒 ~ 3 分 30 秒
> 版本：v1.0（基于 Pix Web 1.53.1）

---

## 一、视频整体定位

- **目标观众**：独立游戏开发者、像素美术爱好者、Game Jam 选手、独立工作室美术。
- **核心卖点**：一句话——**"输入一句描述，直接拿到能进游戏引擎的真·像素画素材"**，而不是糊一张看起来像像素的图。
- **整体节奏**：开头 10 秒抓人，中间 3 个功能演示各 30~40 秒，结尾 20 秒收束。
- **关键差异点**：
  - 真·像素画：每一格就是一个像素，无抗锯齿、无渐变模糊。
  - 调色板严格受控（用户设置颜色数上限）。
  - 平铺纹理保证四边无缝拼接。
  - 序列帧支持 mosaic 单图模式 + 浏览器内 CSS 切帧预览。
  - 「调整」编辑器本地重合成，不扣点。

## 二、宣传文案（可直接当解说词念）

### 开场（0:00 – 0:15）

> 做独立游戏的时候，最让人头疼的不是写代码，是缺图。
>
> 想要一个 32×32 的物品图标、一张能无缝平铺的草地、一组角色行走动画——要么自己画半天，要么用 AI 生成完发现根本不是"像素画"，颜色糊成一团，还得手动一格一格修。
>
> 我做了一个工具，叫 **Pix**。一句话描述，直接出能进游戏的像素素材。

### 第一段：物品图标（0:15 – 0:55）

> 先看最常用的——**物品图标**。
>
> 比如我要一把"赤焰长剑"。在主体输入框里写上名字，选好画布尺寸，比如 32×32，颜色数限制 12 色，剩下的交给 Pix。
>
> 后端会自动拼好完整 prompt，调用图像模型出图，然后在本地走一整套像素化管线：完美像素对齐、纯色背景抠透明、贴着主体裁剪、补到目标画布。
>
> 出来的图是**真·像素画**——每一格就是一个像素，没有抗锯齿、没有渐变模糊，调色板严格控制在你设定的颜色数以内。下载下来直接拖进 Unity、Godot、RPG Maker 都能用。

### 第二段：平铺纹理（0:55 – 1:30）

> 第二个常用的是**平铺纹理**。地砖、木板、草地、墙面、地毯，地图里反复用到的那种。
>
> 切到「平铺纹理」模式，描述写"中世纪石板路"，提交。
>
> Pix 会强制让图案**铺满整张画布、四边无缝拼接**，不留透明背景。出图后本地做完美像素对齐，自动检测最优网格——通常落在 32×32 到 128×128 之间。
>
> 主页右侧的预览框会用 4×4 的方式实时拼接展示，让你一眼看出实际铺到地图里是什么效果。无缝、不重复感、可直接当 tileset 用。

### 第三段：序列帧动画（1:30 – 2:15）

> 最让我得意的一块——**序列帧动画**。
>
> 选「序列帧」模式，画布尺寸 64×64，行列设成 1 行 8 列，描述里写"骑士挥剑动作"，提交。
>
> Pix 用一次 API 调用直接出整张 8 格的 mosaic 大图，再在本地按格切分、统一调色板、对齐裁剪，最后输出一张横向 sprite sheet 加一个 sequence.json，引擎里直接能播放。
>
> 如果想让所有帧用同一个角色，上传一张参考图，Pix 会切到图生图模式，每一帧都基于这个角色去画。
>
> 切完发现某一帧主体偏了？打开作品库的「调整」编辑器，**拖动、滚轮缩放、半透明影子叠在上一帧上做对位**——保存的时候只在本地重合成，不重新调用 AI，不再扣点。

### 第四段：作品库 & 计费（2:15 – 2:45）

> 所有生成结果都进作品库。每张图都能展开看完整参数：当时的 prompt、模型、像素化设置、计费快照、输出文件路径，一键复制 JSON，方便复现或排查。
>
> 计费按点数走，物品图标和纹理一次一张，序列帧按 9 帧一档计价，8×8 满格也就 40 点。新用户注册送点，邀请好友双方都返点。

### 收尾（2:45 – 3:00）

> Pix 现在已经上线，浏览器打开就能用，不需要装任何东西。
>
> 链接放在简介里，欢迎来试。如果你正在做独立游戏，希望它能帮你省下画素材的时间——把精力留给真正重要的事：你的游戏本身。

## 三、录制步骤（按时间线对应文案）

### 准备阶段

#### 1. 环境检查

- 把后端、worker、前端全跑起来，本地访问没问题：
  - `pix-web-api`
  - `pix-web-rq-worker`
  - `cd apps/web && npm run dev`
- 确认账户里点数够，至少留 200 点保证序列帧能跑完。
- 提前把要演示的 3 个 prompt 想好，建议：
  - 物品 = "赤焰长剑" 或 "魔法蓝色药水瓶"
  - 纹理 = "中世纪石板路" 或 "森林草地"
  - 序列帧 = "骑士挥剑 8 帧" 或 "史莱姆跳跃 6 帧"
- 如果有不错的角色参考图，提前放在桌面方便拖拽演示图生图。

#### 2. 录屏设置

- 屏幕分辨率：1920×1080 或 2560×1440，统一一档不要切换。
- 录屏工具：OBS（免费、好控）或 ScreenStudio（Mac 好看）。
- 浏览器开**无痕模式**，干净 UI，关掉所有插件图标。
- 把浏览器缩放调到 100%，字体清晰，防止录出来糊。
- 关闭微信、QQ、邮件通知，全屏 do-not-disturb。
- 如果要露脸 / 语音，提前调好麦克风电平，找安静房间。

#### 3. 资源准备

- 准备一张 logo 或开场卡（Pix 名字 + slogan）。
- 准备一段轻量背景音乐（lo-fi、chiptune 风格契合主题），音量压到 -20 dB 以下不抢解说。
- 简介模板提前写好（视频结尾用）。

---

### 录制阶段（按 7 段拍）

> **Tip**：每段单独录，录废了重来一段就行，不要从头到尾一次性录。后期剪起来轻松很多。

#### 段 1：开场卡（10 秒）

- 录一段标题动画 / 静态卡，叠 logo + 主标题。
- 不需要在网站里录，用剪辑软件做就行。
- 文案对应"做独立游戏的时候，最让人头疼的不是写代码，是缺图……"

#### 段 2：物品图标演示（30~40 秒）

- 浏览器进首页 → 滚到 hero 区让 logo + slogan 露 1~2 秒。
- 进**「工作台」**（WorkspacePage）。
- 选「物品图标」素材类型，画布选 32×32，颜色数选 12，主体输入框打字"赤焰长剑"。
  - **重要**：打字过程要录下来，不要直接粘贴，让观众看到输入。
- 点提交，提交后停留在任务进度卡上 2~3 秒，然后**剪掉中间等待时间**。
- 直接跳到结果展示：放大成品 PNG，用一个小动画放一下"原图 vs 实际像素格"对比（可选，能加分）。
- 演示一下作品库展开，看一眼参数面板。

#### 段 3：平铺纹理演示（30~40 秒）

- 切到「平铺纹理」素材类型。
- 输入"中世纪石板路"，提交。
- 跳过等待时间。
- 重点录**主页那个 4×4 平铺预览**：左原图、右预览框，强调"无缝拼接"。
- 鼠标悬停 + 滚动一下让画面有动感。

#### 段 4：序列帧演示（40~50 秒，重头戏）

- 切到「序列帧」模式。
- 画布 64×64，rows=1，cols=8，描述"骑士挥剑动作 8 帧"。
- 如果要演示参考图：拖一张角色图进上传框，UI 切换到图生图模式（这里可以特写）。
- 提交，跳过等待。
- 结果出来：作品库里的 sprite 卡片会**自动循环播放**动画——录这个循环至少 3 秒，让观众看清楚。
- **再来一段「调整」编辑器演示**：
  - 点开调整面板，拖动其中一帧的主体（让影子叠加效果露出来）。
  - 滚动滚轮缩放一帧。
  - 点保存，强调"本地重合成，不扣点"。

#### 段 5：作品库 & 参数快览（15~20 秒）

- 进 **GalleryPage**。
- 点开任意一张作品的「参数」按钮。
- 展示完整 JSON 面板，鼠标移到「复制 JSON」按钮上停 1 秒。

#### 段 6：计费 & 邀请（10~15 秒）

- 进 **BillingPage** 露一下点数余额。
- 进 **RewardsPage** 简单晃一下邀请链接。
- 不用细讲，让观众知道"有这功能"就行。

#### 段 7：收尾卡（10~15 秒）

- 录一段结尾静态卡：网站 URL + "现在就来试试"按钮 + logo。
- 不需要在网站里录。

---

### 后期剪辑要点

1. **每段开头 + 结尾留 0.5 秒空白**，方便剪辑接缝。
2. **加速等待画面**：所有"任务进行中"的等待统一加 8x~16x 速度，或者直接剪掉，配一个 "几秒后……" 的字卡。
3. **关键操作放慢**：点击提交、拖动调整器、参数 JSON 复制这些瞬间，可以做 0.5x 慢放或者加 1 秒的画面停顿，让观众跟得上。
4. **重点信息打字幕**：尺寸、颜色数、模式名这些参数，叠在画面右上角小字幕，不要全靠语音。
5. **配色统一**：字幕、字卡用网站本身的配色（暖色系像素风），整体感强。
6. **背景音乐**：选一首 lo-fi / chiptune，副歌部分留给"调整器"那段重头戏。
7. **结尾必须出现**：网站 URL（大字号）、产品名、一句行动号召（"现在就来试 →"）。

## 四、可选加分项

- **开场前 3 秒放一段「结果蒙太奇」**：把后面要演示的 3 个最终成品快剪在一起，配一句"这些素材，全是 AI 几秒钟生成的"。这种结构特别抓人，转化率高。
- **真实使用场景**：录一段把生成的 sprite sheet 拖进 Godot / Unity / Aseprite 的镜头，10 秒就够，但说服力翻倍。
- **对比镜头**：放一张普通 AI 生图（糊的）vs Pix 生图（每格都是真像素）的左右分屏，2 秒。
