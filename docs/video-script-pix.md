| 维度 | 卖点 |

## 三、开头钩子镜头脚本（黄金 5–8 秒）

> 目标：前 3 秒让用户"愣一下"，前 5 秒不划走。
> 结构：**痛点曝光 → 反差揭示 → 产品爆发 → 产品亮相**。

### 3.1 总览（8 秒钩子）

| # | 时间 | 镜头内容 | 音效 / BGM | 字幕 | AI 出图 / 出片 Prompt |
|---|---|---|---|---|---|
| 1 | 0.0–1.5s | 凌晨 2 点像素风工作室桌面：3 个空文件夹、1 杯凉咖啡、1 个 Discord 红点未读"美术今天交不了"。冷蓝色调，CRT 扫描线滤镜。 | 闹钟低频 tick + 微弱键盘声 | （无字幕，让画面说话） | `top-down pixel art desk at 2 AM, empty asset folders, cold blue tone, CRT scanline, lonely game dev workspace, 16-bit aesthetic` |
| 2 | 1.5–3.0s | 镜头快推到屏幕：素材文件夹只有 3 张占位 "?" 图，旁边 Trello 卡片闪红 "逾期 3 天"。 | tick 突然停 0.2s | 顶部硬切大字（黑底黄字）：**"独立游戏卡在美术上的第 3 天"** | `close-up of game dev folder with 3 placeholder question mark sprites, red overdue label, panic energy` |
| 3 | 3.0–4.0s | 一只手敲下回车，画面像素被一帧"碎裂 / 翻转"切换。底色由冷蓝瞬切暖橙。 | 玻璃碎裂 + 上扬 "叮" 音效（强 hook 节点） | （无字幕） | 转场：pixel-mosaic dissolve / glitch flip |
| 4 | 4.0–6.0s | 网格化爆出 16 个像素图标同时落位（剑、药水、地砖、火球动画、骑士走路帧）。所有素材尺寸统一、背景透明（棋盘格底）。 | 4 连击 "哒哒哒哒" + 上行 BGM 起 | 中央大字逐字打出：**"10 分钟，做完一整套像素素材"** | `16 pixel art icons popping into a transparent checkerboard grid: sword, potion, brick tile, fireball animation, knight walk cycle, unified palette, perfect pixel grid, 64x64` |
| 5 | 6.0–8.0s | 切到 Pix 网站工作台 mockup：左侧输入框写"暗月骑士 64×64"，右侧网格里 8 张统一像素 PNG 同时生成。鼠标点"导出 ZIP"。 | BGM 进副歌前的"收" + 一声 "咔" | 底部硬字：**"Pix · AI 像素素材工作台"**<br>小字：**"链接在评论区"** | `screenshot-style: clean light UI, prompt input "Darkmoon knight 64x64", 8-up pixel asset preview, export-zip button highlighted` |

### 3.2 节奏带

```
0.0 ─────── 痛点冷场 ──────── 1.5
            ↓ 留白 0.2s（让观众屏息）
1.7 ─────── 痛点字幕 ──────── 3.0
            ↓ 玻璃碎裂转场 ★关键 hook
3.0 ─────── 反差暖切 ──────── 4.0
4.0 ─────── 素材爆发 ──────── 6.0
6.0 ─────── 产品亮相 ──────── 8.0
```

### 3.3 钩子设计逻辑（写给剪辑团队）

1. **第 1 秒不出现产品**——直接用"凌晨 2 点 + 空文件夹"勾出独立游戏人的集体记忆。
2. **第 3 秒制造反差**——冷蓝 → 暖橙，安静 → 爆破，强迫视网膜留下来。
3. **第 5 秒给承诺**——"10 分钟做完一整套"，卖点直接钉死。
4. **第 8 秒才说产品名**——前期替用户解决问题，最后落款，转化率更高。

## 五、AI 工具与素材搭配建议

| 用途 | 推荐 |
|---|---|
| 图像 / 分镜定帧 | Midjourney、即梦、Sora 2、gpt-image-2 |
| 像素素材本身 | **直接用 Pix 自产**（结尾自产自销更有说服力） |
| 转场 / 动效 | Runway Gen-3、Pika、CapCut 的"像素马赛克"过渡 |
| BGM | 8-bit 上行电子（关键词 `chiptune build-up` / `pixel adventure intro` / `lo-fi 8bit hopeful`） |
| 字体 | 中文：站酷快乐体 / 阿里妈妈方圆体；英文：Press Start 2P |
| 屏幕录制 | OBS（推荐）/ ScreenToGif（用于像素动效） |

## 七、拍摄 / 剪辑检查清单

### 7.1 必须有
- [ ] 前 3 秒不出现产品名
- [ ] 第 3 秒前后有强转场（视觉 + 音效双 hook）
- [ ] 字幕在屏幕中部偏上 1/3，避开抖音点赞按钮区
- [ ] 像素素材使用棋盘格透明底（让"透明 PNG"卖点可视化）
- [ ] 结尾留 1 秒静帧给评论区引导

### 7.2 不要有
- [ ] 旧 64×64 / 32×32 outline 对比图（清单里已淘汰，不要再剪进去）
- [ ] 任何 `#FF00FF` 紫色背景（产品早就不用固定 key 色了）
- [ ] 长镜头 3 秒以上不切（短视频节奏会死）
- [ ] AI 一眼可见的"涂抹感"画风（必须是真像素 / 网格对齐）
