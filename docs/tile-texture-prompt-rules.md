# 平铺纹理 Prompt 细分规则

Pix 的 `asset_kind=tile_texture` 用于生成像素游戏地图里可重复铺开的纹理。它不使用普通「主体居中 + 透明背景」素材模板，而是始终使用专用平铺纹理 prompt：铺满画布、四边无缝、非透明背景、像素硬边、限制颜色数。可选 `style_profile` 会作为项目统一风格补充追加到专用 prompt 后面，不会替换四边无缝、铺满画布和非透明背景等硬约束。

## API 字段

```json
{
  "job_type": "asset",
  "asset": {
    "name": "苔藓石板路面",
    "asset_kind": "tile_texture",
    "subject_kind": "tileable_pattern",
    "texture_kind": "path_floor"
  },
  "style_profile": {
    "project_name": "Crystal Dungeon",
    "palette": "cyan, violet, deep navy",
    "avoid_elements": "modern objects, text, watermark"
  },
  "pixelize": {
    "output_size": [32, 32],
    "colors": 12,
    "remove_bg": false
  }
}
```

- `texture_kind` 默认值为 `auto`。
- 当 `texture_kind=auto` 或未传入时，后端会根据 `asset.name` 与 `asset.extra_prompt` 关键词推断类型。
- 生成元数据会记录：
  - `asset.requested_texture_kind`：请求值。
  - `asset.resolved_texture_kind`：最终用于 prompt 的类型。

## 通用硬约束

所有平铺纹理类型都必须遵守：

1. 画布尺寸必须与目标像素尺寸一致，例如 `32x32`。
2. 每个像素是一个硬边方格，禁止抗锯齿、软笔刷、平滑混色。
3. 图案必须铺满整张画布，不能留透明区域、纯色外框、暗角或边缘留白。
4. 左边必须能接右边，上边必须能接下边，重复铺开时不能出现明显接缝。
5. 不生成文字、水印、边框、居中主体、单个物件或会暴露重复的大型焦点。

## 纹理类型

| texture_kind | 适用场景 | Prompt 规则 |
|---|---|---|
| `auto` | 用户不想手选类型 | 根据主题关键词推断；未命中时使用 `generic_texture`。 |
| `generic_texture` | 其它材料、抽象地图材质 | 保持均匀、可重复的表面节奏；避免地标、徽章、物体、角色、水平线、投影和明显中心。 |
| `terrain_ground` | 草地、泥地、沙地、雪地、苔藓、碎石地表 | 俯视 RPG 地形；自然噪声均匀分布，可行走，不出现居中树、石堆、道路边界、墙面或大型物件。 |
| `path_floor` | 石板路、砖路、室内地砖、广场地面 | 俯视可行走路面；砖缝、石缝、裂缝跨边缘对齐，避免墙、门、地毯外框或中心徽章。 |
| `wall_surface` | 墙壁、砖墙、岩壁、洞壁、城墙 | 正面墙体 / 岩壁；统一左上光照，砖块、裂缝、灰浆、苔藓痕迹连续；避免地面透视、天空、窗门、火把、架子和完整建筑立面。 |
| `wood_planks` | 木板地、木墙、树皮、甲板 | 木纹、节疤、裂缝、板缝跨边连续；保持材质条带，不要变成桌子、箱子、牌匾、画框或单根原木。 |
| `water_liquid` | 水面、岩浆、毒液、酸液、史莱姆液 | 可作为动画底帧；波纹、高光、泡沫、气泡、发光流线跨边连续；避免岸线、岛、船、瀑布、角色和一次性大高光。 |
| `foliage_canopy` | 树冠、灌木、藤蔓、草丛覆盖层 | 叶团、枝隙和绿色层次密集分布；保持连续覆盖，不出现树干、花束、单株植物图标或透明洞。 |
| `roof_tile` | 瓦片、木瓦、茅草屋顶 | 重复屋瓦行，重叠节奏清晰，行偏移跨边对齐；避免烟囱、天窗、屋顶轮廓、房屋剪影、排水沟或地面透视。 |
| `metal_panel` | 科幻金属地面、工业墙、机械面板 | 面板缝、铆钉、螺丝、划痕、通风口、警示条碎片跨边对齐；避免可读文字、Logo、屏幕、按钮焦点、武器或单个机器零件。 |
| `fabric_carpet` | 布料、地毯、挂毯、编织纹样 | 编织线迹、小纹样、条纹或几何重复跨边连续；避免外边框、流苏、中央大徽章、可读符号或单件布料轮廓。 |

## 设计原则

- **地图地面**优先俯视角，避免透视和投影。
- **墙壁/岩壁**优先正面材质面，避免混成地砖。
- **液体**只表达连续表面，不表达岸边关系；岸边应由单独边缘 tile 解决。
- **屋顶、地砖、金属面板**可以有规律结构，但结构线必须跨边缘闭合。
- **装饰纹样**可以重复，但不能生成单个完整图标，否则铺开后重复感过强。
